# Поделись мнением — обработка опроса

Веб-инструмент для обработки результатов ежемесячного опроса вовлеченности.

## Что делает

- Принимает экспорт из Superset-дашборда «HR | Поделись мнением» (или совместимый xlsx)
- Фильтрует «лишние» вопросы (на которые ответили не все круги)
- Окрашивает результаты по порогам: <6 красный, 6–6,9 жёлтый, 7–7,9 фиолетовый, ≥8 зелёный
- Считает агрегаты, генерирует PNG-картинку и xlsx
- Формирует пост с подставленными цифрами
- Сравнивает текущий период с предыдущим, ведёт историю в браузере
- Показывает отдельный блок аналитики для HR (не идёт в публикацию)

## Локальный запуск

Открыть `index.html` в браузере — всё, никакой установки не нужно.

## Размещение в сети (хостинг)

Файл полностью статический. Подходят любые хостинги статики:

### Netlify (бесплатно, ~3 минуты)
1. Зарегистрироваться на netlify.com
2. На главной — drag-and-drop этой папки в зону «Drag and drop your site folder here»
3. Получаешь публичную ссылку вида `https://xxx.netlify.app`
4. (Опционально) В Settings → Domain — задать своё имя поддомена

### Vercel / GitHub Pages / Cloudflare Pages
Любой из этих сервисов работает по той же логике — загружаешь папку, получаешь ссылку.

### Внутренний хостинг (рекомендуется для корпоративного использования)
Передать архив команде инфраструктуры с просьбой развернуть на внутреннем поддомене.
Из требований: nginx/apache или любой статический хостинг. Никаких бэкендов и БД не нужно.

## Требования к данным

Файл должен содержать лист «Детализация вопросов» (или быть первым листом) со структурой:
- Колонка A — название темы (опционально, может быть пустой для повторов)
- Колонка B — текст вопроса
- Далее — столбцы по кругам с заголовками вида «ID | Название круга» (например, «1 | PARTNERS»)
- Значения — средние оценки по кругу (числа)

## Хранение данных

Всё хранится в браузере пользователя (localStorage). На сервер ничего не отправляется.
История загрузок и настройки привязаны к конкретному устройству/браузеру.

## Используемые библиотеки (через CDN)

- SheetJS (xlsx) — чтение и запись эксель-файлов
- html2canvas — генерация PNG из HTML-таблицы
- FileSaver — скачивание файлов

При отсутствии интернета нужно скачать эти библиотеки локально и подменить пути в `index.html`.
